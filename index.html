PROJECT OVERVIEW

Objectives & Conclusion

Project Objectives

  • Understand remote communication protocols.
  • Study the security limitations of TELNET.
  • Understand SSH encryption.
  • Compare default ports and security features.
  • Demonstrate why secure remote access matters.

Conclusion

TELNET does not encrypt its traffic, creating a risk of credential exposure. SSH protects communications through encryption and integrity protection and supports server authentication when configured correctly. SSH is therefore preferred for secure remote administration.
